## B. Scope

- `system`: **Dual.** (i) GPCR — human dopamine D1 receptor (DRD1), residues 21–346 of UniProt P21728 (pp. 3–4); (ii) bacterial receptor histidine kinase sensor domain — *E. coli* BarA Cache sensor domain, residues 31–178 of UniProt P0AEC5 (pp. 3–4, 10). Only the periplasmic ligand-binding sensor domain of BarA is modelled, not its kinase domain (p3).
- `n_targets`: 2 proteins. Two ligand chemotypes (methylamine/methylammonium on DRD1; acetic acid/acetate on BarA). The paper draws general conclusions about four co-folding methods from these two systems (pp. 12–13).
- `method_class`: benchmark-only — a systematic probe of four existing co-folding methods; no new method is introduced. (pp. 2–3)
- `backbones`: AlphaFold 3 v3.0.1; Boltz-2 v2.2.1 (default v2 weights); Chai-1 v0.5.2 (default weights); Protenix-v1 code v1.0.0 (default weights). All run locally on an RTX 4090. (p3) Four backbones head to head → tagged `multi-backbone`.
- `templates`: **off** for AlphaFold 3 — "MSA generation was first performed for a protein without ligand, and then the MSA without templates was transferred to the input JavaScript Object Notation (JSON) files for complex predictions" (p3). For Boltz-2, Chai-1 and Protenix-v1 template usage is **NOT REPORTED**; only MSA provenance is described (p3).
- `msa_handling`: **full + pinned.** Full MSAs (HMMER 3.4 for AF3; a local ColabFold MSA server for Boltz-2, Chai-1, Protenix-v1), generated **once for the ligand-free protein and then reused for every complex prediction** — "the MSAs were first generated during structure prediction without ligands and then used for complex prediction" (p3). Not subsampled, not clustered, not state-filtered. The pinning is a deliberate control: it holds the protein-side input byte-identical across all ligand and format arms.

## C. Conformational core

- `states_generated`: **ensemble (of ligand poses), single protein conformation.** 500 diffusion samples per ligand × input-format arm, all retained and analysed, giving an ensemble of ligand placements (p3). Protein conformational states are **not an object of study**: every model is superimposed on a single ligand-free AlphaFold 3 model of the same target and only ligand coordinates are then analysed — "All models for a certain protein target were superimposed based on the protein backbone atoms onto the structure of the same target generated in Alphafold 3 with no ligand. After that, the ligand atom coordinates were extracted and analysed." (p3). No protein-side conformational metric is reported anywhere in the paper.

- `structural_priors_used`:
  1. **DRD1 expected binding mode taken from a deposited experimental structure** (ref 28, Zhuang et al. 2021, human D1 receptor cryo-EM): "Binding of dopamine and chemically related molecules to the receptor involves formation of an ionic bridge between the amino group of the ligand and the carboxylate group of D103 [28]." (p4). Fig. 3A caption: "Predicted positions are predominantly observed around the expected amino group position in known ligands." (p9)
  2. **BarA putative site taken from modelling + docking + mutagenesis, not a structure** — "For the BarA sensor Cache domain, no experimental structure was publicly available at the moment of the analysis. Structural modeling, docking and mutagenesis place the ligand binding site in the vicinity of L95, T98, I130, T133 and I136.[29]" (p10); also "Putative ligand binding pocket of BarA is composed of hydrophobic and polar residues L95, T98, and I136 [29]." (p4)
  3. **Residue ranges chosen from prior structural knowledge of domain boundaries** — "To facilitate the predictions and limit the modeled region to ordered ligand-binding domain, we used residues 21-346 ... and residues 31-178 ..." (p3)
  4. **Ligand identifiers taken from PDB-derived chemistry databases** — CCD codes NME / 3P8 / ACY / ACT from PDBeChem, SMILES from PubChem (p3). Note that a CCD code is itself a pointer into the PDB chemical dictionary the models were trained against; this is the very asymmetry the paper probes, not a leak of the target complex.
  5. **Reference bond-length ranges are quantum-chemical, not structural** (refs 30–37) — "Reference ranges obtained using quantum chemical calculations" (Figs 1, 2 captions, pp. 5, 8; Table 1, p6). These are a physics prior, not a deposited-structure prior.
  6. **Ligand choice justified by training-set ubiquity** — "These moieties are commonly found at the N- and C-termini of proteins, as well as in the side chains of lysine, aspartate and glutamate. As such, they are ubiquitous in the publicly available structures from the PDB [44], and undoubtedly present in the training sets of co-folding tools." (p11). This is a deliberate design choice to make the test maximally favourable to the models.

- `oracle_leakage`: **route 7 only (design-level). No pipeline leakage found.** Routes considered separately:

  1. **Structures used as input or template** — `NONE FOUND`. AF3 run with MSA only, templates explicitly stripped: "the MSA without templates was transferred to the input JavaScript Object Notation (JSON) files for complex predictions" (p3). No deposited complex is supplied to any model. Protocol described p3. For Boltz-2/Chai-1/Protenix-v1 the template setting is not stated (see `unresolved`).
  2. **State annotations from a curated database (GPCRdb, KLIFS, Kincore) driving templates or alignments** — `NONE FOUND`. No such database appears anywhere; MSAs come from HMMER and a local ColabFold server (p3).
  3. **Cluster labels derived from known states** — `NONE FOUND`. PCA is unsupervised and fitted on the predicted ligand coordinates themselves: "Principal component analysis (PCA) was performed using the Scikit-learn Python module" (p3); Fig. 3A caption "PC1 and PC2 are the principal components for the carbon atom positions of the ligands" (p9). No labels from known structures enter the projection.
  4. **Hyperparameters, sweep ranges, seeds or stopping criteria tuned against known states** — `NONE FOUND`. Default weights and fixed, pre-declared sampling budgets throughout: "run with the default version 2 weights" (Boltz-2), "run with the default weights 50 times with 10 diffusion samples" (Chai-1), "the 1.0.0 version of the code and default weights 50 times with seeds from 1 to 50" (Protenix-v1), "100 different random seed values with 5 diffusion samples generated per seed" (AF3) — all p3. No range was swept and no per-target value chosen.
  5. **Success defined post hoc by RMSD or TM to a structure they had** — `PARTIAL, and not by RMSD`. For **DRD1** the correctness call is made against a deposited experimental binding mode held by the authors — "we find that methylammonium is preferentially positioned at the expected position by all tools" (p12) — but the judgement is visual/distributional (PCA + eye), not an RMSD-to-reference score. For **BarA** no deposited structure existed, so the reference is a docking/mutagenesis-derived putative site (p10) and is not an oracle at all. Critically, **the paper's headline comparison — CCD vs SMILES, and charged vs neutral, within the same model — is reference-free**: the KS statistic compares two prediction distributions to each other, never to a structure (Figs 3B, 4B; pp. 9–10). No RMSD or TM appears anywhere in the paper.
  6. **Best/worst model labels assigned against a held reference** — `NONE FOUND`. No model selection or ranking of any kind; all 500 samples per arm enter the distributions (p3, and Figs 1–4 which plot every sample).
  7. **Design-level oracle use — systems or conditions chosen because the expected answer is already known** — `PRESENT, and explicit`. Both systems were selected because the physically expected outcome could be declared in advance, verbatim (p4): "Accordingly, charged methylammonium ion is expected to be positioned near D103 by the algorithms, whereas neutral methylamine is likely to be bound elsewhere, if at all." and "Accordingly, neutral acetic acid is expected to be positioned near these residues, whereas negatively charged acetate ion should not occupy the pocket." Also (p11): "we chose methylamine and acetic acid as two of the simplest titratable probes ... undoubtedly present in the training sets of co-folding tools."
     **This is design-level, not pipeline leakage**, and it is the weaker form: the expected answer shapes what counts as a pass, but nothing about it reaches the model's input. For the format-invariance half of the study it is irrelevant — that half needs no expected answer at all.

- `prospective`: **partial.**
  - *Format-invariance arm: effectively prospective / reference-free.* CCD-vs-SMILES is an internal-consistency test between two of the model's own outputs. No deposited structure is needed or used to score it (pp. 8–10).
  - *Charge-correctness arm: retrospective at the design level.* The expected direction of the charge effect was declared from prior experimental literature before the results were read (p4, refs 28–29), and the bond-length reference ranges come from published quantum-chemical work (Table 1, p6).

- `state_metric`: **NOT APPLICABLE as a conformational-state metric** — the paper measures ligand pose and ligand internal geometry, never a protein conformational state (see `states_generated`). Recorded honestly, the placement/geometry metrics are **dual: continuous coordinate + visual only**:
  - *Continuous:* Kolmogorov–Smirnov statistic between the distributions of the ligand's carbon (DRD1) or carboxyl-carbon (BarA) atom positions projected on **PC1 only**, "equal to 0 for identical distributions and to 1 for non-overlapping distributions [39]" (p8; Figs 3B, 4B captions pp. 9–10). Computed with SciPy (p3).
  - *Continuous:* interatomic distances (N–C, C–C, C–O) compared to quantum-chemical reference ranges (Table 1 p6; Figs 1–2 pp. 5, 8).
  - *Visual only:* whether a pose lands at the expected site is called by eye from the PCA scatters and structure overlays — "the ligands are mostly positioned close to the expected amino group location observed in experiments (Fig. 3)" (p8); "None of the algorithms recapitulate this putative binding site (Fig. 4)" (p10).
  - **Thresholds: NOT REPORTED.** The paper uses "extremely sensitive", "only slightly distinguishable", "somewhat dependent", "mostly independent" (pp. 8–10) with **no stated KS cutoff, no significance test and no p-value anywhere**. There is also no distance cutoff defining "at the expected position".

- `metric_saturation`: **Yes, at the ceiling, in two cells.** The KS statistic is bounded on [0, 1] by construction ("ranges from 0 for identical distributions to 1 for non-overlapping ones", Fig. 3B caption p9). Boltz-2, methylammonium SMILES vs CCD, reaches **KS = 0.996** (Fig. 3B, p9) — the two distributions are essentially disjoint and the metric can record nothing beyond that. AlphaFold 3, acetate CCD vs SMILES, reaches **KS = 0.988** (Fig. 4B, p10). Boltz-2 methylamine SMILES vs CCD is 0.89 and AF3 acetate-vs-acetic-acid CCD is 0.844 (pp. 9–10). In these arms the metric cannot distinguish "completely different pose" from "completely different pose, further away". No floor saturation is reached (minimum 0.018, AF3 methylammonium format contrast, p9). Axis truncation in Figs 1 and 2A is a figure defect and is recorded in `hides`, not here.

- `directional_control`: **The tested handle is the ligand specification itself**, in two forms, and neither works as a directional control:
  - *Input format (CCD code vs SMILES string)* — should be a no-op and is not; it is an unintended handle. AF3, Boltz-2 and Protenix-v1 accept both; Chai-1 accepts SMILES only, so it has no format handle at all — "Given that Chai-1 only accepts SMILES as the input format, CCD input was not tested." (p3)
  - *Formally specified charge / protonation state* — should be a genuine handle and is a weak and mis-signed one: "we find that even though the input formats allow direct specification of charge, resulting predictions do depend on charge, yet this dependence does not follow any pattern that would be expected from basic physical and chemical principles (Figs. 3 and 4)" (p12).
  - No partner, nanobody, peptide, template, state-filtered MSA, seed or subsample-depth handle is used. Seeds vary only to generate the ensemble, not to steer it (p3).

- `anti_memorization_design`: **NONE.** There is no training cutoff, no post-cutoff set, no held-out set and no similarity filter anywhere in the paper. The design is the deliberate opposite: ligands were chosen *because* they saturate the training data — "ubiquitous in the available training sets and expected to be modeled well" (p2), "undoubtedly present in the training sets of co-folding tools" (p11). The nearest thing to a held-out case is incidental and n = 1: **BarA**, for which "no experimental structure was publicly available at the moment of the analysis" (p10) — i.e. the complex could not have been memorised because it does not exist in the PDB. No cutoff date is given for this claim.

- `anti_memorization_control`: **NONE RUN, and UNPOWERED if the BarA case is counted.** The BarA arm is never framed or analysed as a memorisation control; it is presented as a second chemistry system. Its result is used only interpretively, post hoc, without any matched in-training comparator: "For BarA, none of the co-folding algorithms recapitulate the expected configuration of the acetate binding site, which might be the consequence of absence of similar molecular arrangements in the training sets ... Overall, our findings correspond to larger benchmarks that found a correlation between presence of a ligand in the training set and success rate of a corresponding prediction [7, 12, 13]." (p12). n = 1 target, so `UNPOWERED`.

- `confidence_as_discriminator`: **NOT REPORTED / not used.** pLDDT, pTM, ipTM, PAE and per-ligand confidence scores appear nowhere in the paper. No sample is ranked, filtered or selected by confidence; every one of the 500 models per arm is analysed (protocol, p3; and all samples are plotted in Figs 1–4). Consequently there is also no validation of confidence as a correctness signal.

## D. Claims

- `central_conclusion`: Feeding four co-folding models (AF3, Boltz-2, Chai-1, Protenix-v1) the *same* small titratable ligand under two interchangeable encodings — a PDB Chemical Component Dictionary code versus a SMILES string — changes the predicted ligand pose, and in several model/ligand combinations changes it more than switching the ligand's actual protonation state does. Meanwhile the explicitly declared formal charge does alter predictions, but not in the direction physics requires: predicted bond lengths move the wrong way with protonation in all but one case, and neither the DRD1 nor the BarA charge preference is recovered. The authors conclude the field needs (i) format-invariant results and (ii) protonation-aware training and prediction pipelines.

- `necessity_claims` (verbatim + page):
  - "This presents two clear paths for improvement of protein-ligand structure prediction algorithms: (i) ensuring identical results irrespective of the input formats, and (ii) inclusion of protonation-related steps into training and prediction pipelines." (p13, Conclusions)
  - "Overall, this raises an important point that if diverse predictions are desired while using the current versions of the methods, all possible input formats and molecular charges should be tested, whereas any conclusions derived from the charge-induced differences should be treated cautiously." (p13)
  - "Thus, the mentioned issues remain to be solved and present an opportunity for further improvement of biomolecular structure prediction approaches; in the meantime, co-folding results obtained using AlphaFold 3, Boltz-2, Chai-1 and Protenix-v1 should be interpreted with caution." (p13)
  - "Protonation cannot be deduced directly when using two of the most popular experimental structural biology methods, X-ray crystallography and cryo-electron microscopy, and thus the information on protonation of amino and carboxy groups is lacking from PDB." (p12) — an impossibility claim about the *data*, and the paper's stated root cause for the models' charge-blindness.
  - "For protonated acetic acid, where the two C-O bonds are expected to be of different lengths due to different valency, none of the tools capture this effect (Fig. 2B)." (p11)
  - "None of the algorithms recapitulate this putative binding site (Fig. 4)." (p10)
  - "Given that Chai-1 only accepts SMILES as the input format, CCD input was not tested." (p3) — a scope impossibility, not a defect claim.
  - "For the BarA sensor Cache domain, no experimental structure was publicly available at the moment of the analysis." (p10)

- `novelty_claims` (verbatim + page): **NO EXPLICIT PRIORITY OR FIRST-CLAIM IS MADE.** The paper never uses "first", "novel" or "unprecedented" of its own work, and it explicitly situates itself alongside prior probes (refs 10–14, p2; "Overall, our findings correspond to larger benchmarks", p12). The nearest statements are surprise claims, recorded verbatim because they carry the paper's rhetorical weight:
  - "Unexpectedly, we found that for both molecules, in many cases the input format affected the prediction results, and did it much stronger compared to protonation, whereas changes in the formally specified charge of the molecules did not lead to changes in binding expected from experiments." (p1, Abstract) — **the central finding, quoted verbatim as requested.**
  - "Unexpectedly, we found that in many algorithm-molecule combinations, the input format affected the results of the prediction, whereas charge did not." (p2)
  - "Unexpectedly, we found that the results of the predictions generally depend stronger on the input format rather than on the formally specified charge of the ligand. On the other hand, charge dependence does not follow the expected pattern." (p11)
  - "However, it is completely unexpected that the prediction results are different when the ligand is specified using either CCD or SMILES." (p13)
  - "Quite surprising is also that while the predictions do not reflect charge of the molecule as would be expected from physical and chemical principles, the results depend on the specified charge nonetheless." (p13)
  - The only "first" in the paper is about AlphaFold 3, not about this work: "despite being the first state-of-the-art model capable of handling small molecules, it is not universally available and has a restrictive license" (p2).

- `stated_limits`:
  - Chai-1 cannot take CCD, so the format contrast is simply absent for one of the four models (p3).
  - No experimental structure of the BarA sensor domain complex existed at analysis time; the "expected" site is inferred from modelling, docking and mutagenesis (p10).
  - The Protenix-v1 pathology may be version-specific and transient: "this may be fixed in future releases, as earlier Protenix v. 0.5.0 did not display such deviations" (p11).
  - Format dependence framed as likely transient: "This discrepancy will probably be rectified in the next versions of the algorithms." (p13)
  - Bond-length deviation is acknowledged as already known for AF3 amino acids: "Deviation of amino acid bond length and angle distributions from experimentally observed ones was previously described for AlphaFold 3 [10], so bond length deviations for ligands are not completely unexpected." (p11)
  - The BarA failure is offered a training-data explanation rather than claimed as a model defect: "which might be the consequence of absence of similar molecular arrangements in the training sets. Indeed, partially hydrophobic site binding a protonated carboxy group-containing ligand is not a common occurrence." (p12)
  - No model is singled out: "none of the four popular cofolding methods that we compared clearly stood out in terms of prediction quality" (p13).
  - Reference values are computational (quantum-chemical), not experimental measurements (Table 1 p6; Figs 1–2 captions pp. 5, 8).
  - Not stated by the authors but visible: only two ligand pairs and two targets, and no statistical test on any KS value.

- `stance`: **PROVISIONAL — the user's call.** `precedent on findings + contrast on rigour`.
  - *precedent:* it is direct, quantified, multi-backbone evidence that co-folding ligand placement responds to a semantically null change in ligand encoding and fails to respond correctly to a real chemical change — the exact mirror of a ligand-blindness argument, with numbers and n usable as comparators.
  - *contrast:* rigour gaps are recordable — no anti-memorisation arm at all (by design), no significance testing or threshold on the KS statistic, KS computed on PC1 only, correctness at the expected site called by eye, n = 2 targets, and a design-level oracle (expected answers declared in advance, p4).

## G. Provenance

- `extracted_on`: 2026-09-07
- `extractor`: claude subagent (Opus 5), Claude Code session
- `schema_version`: v3
- `confidence`: **high** for text, Table 1 and all methodological detail — the PDF has a clean text layer and the Methods section is unusually explicit about sample counts. **High** for the KS values in Figs 3B and 4B, which were read from 150 dpi renders of pp. 9–10 and are printed as numerals inside each heatmap cell (four renders total: pp. 5, 8, 9, 10, all deleted after reading). **Medium** for the exact axis ranges quoted in `data_shape`, which were read off rendered tick labels. The BarA C–C reference band on Fig. 2A extends past the plotted range and could not be read precisely from the render; Table 1 was used instead.
- `unresolved`:
  1. **Robustness defect vs desirable chemical sensitivity — the paper does not draw this distinction explicitly, and this is the single most important gap for our purposes.** It does treat the two asymmetrically in its *prescriptions*: format dependence is called "completely unexpected" and the fix is "ensuring identical results irrespective of the input formats" (pp. 13), i.e. the target value is zero; charge dependence is faulted not for existing but for being mis-directed — "resulting predictions do depend on charge, yet this dependence does not follow any pattern that would be expected from basic physical and chemical principles" (p12) — and the fix is "inclusion of protonation-related steps into training and prediction pipelines" (p13), i.e. the target value is nonzero and correctly signed. But **the paper never states in one place that a large format effect is a defect while a large charge effect would be a virtue**, never compares the two effect magnitudes on a common statistical footing (the comparative claim "did it much stronger compared to protonation", p1, is asserted without any test, pooled statistic or per-cell comparison), and never proposes an invariance-vs-sensitivity framing. The mean-KS figures in section E are extractor-computed for exactly this reason and must be labelled as such if used.
  2. **What was varied is narrower than the brief anticipated.** Only two axes were varied: (a) representation — CCD component-dictionary code vs SMILES string; (b) protonation / formal charge — neutral vs charged form. **Tautomers were NOT varied. Stereochemistry was NOT varied** (all four probe molecules are achiral, and stereochemistry is mentioned only when citing prior work, ref 11, p2). No conformer, no isomer, no atom-ordering or SMILES-canonicalisation variation. A SMILES-string-permutation control (same molecule, different but equivalent SMILES) — the cleanest possible representation-invariance test — was **not run**.
  3. **No statistical inference anywhere.** No p-values, no confidence intervals, no bootstrap on any KS value, and no stated threshold separating "different" from "the same". With n = 500 per side, a two-sample KS test would reject at KS ≈ 0.086, which would make almost every cell in Figs 3B and 4B formally "significant" — including cells the paper describes as "only slightly distinguishable" (p10). The paper's qualitative verdicts therefore rest on unstated effect-size judgement, not on a test.
  4. **KS is computed on PC1 only** (p8, Figs 3B/4B captions). Any format- or charge-induced displacement orthogonal to PC1 is invisible to the headline metric. The paper does not report PC1's explained variance, nor whether PCA was fitted per arm, per tool, per target or globally — the Methods say only "Principal component analysis (PCA) was performed using the Scikit-learn Python module" (p3).
  5. **Sampling protocols differ across tools in a way that is not controlled.** AF3 draws 100 seeds × 5 samples, Chai-1 and Protenix-v1 draw 50 seeds × 10, and Boltz-2 draws 500 at once for BarA but 5 × 100 for DRD1 (p3). Seed-level diversity therefore differs by up to 20× between tools, and Boltz-2's own protocol differs between the two targets. The per-tool spread comparisons (e.g. "Chai-1 predictions display the most variance", p7) are confounded by this and the paper does not address it.
  6. **Template settings for Boltz-2, Chai-1 and Protenix-v1 are never stated** (p3 describes only their MSA source). Only AF3 is explicitly template-free. If any of the three defaulted to templates on, the three-tool comparison is not like-for-like.
  7. **The format contrast is structurally undefined for Chai-1** (SMILES only, p3), so the paper's central claim rests on three of four models, and Chai-1 contributes only to the charge contrast.
  8. **The one "correct sign" result may be coincidental.** The paper notes twice that only Boltz-2 with SMILES gets the sign of the charge-induced bond-length change right (p4 for N–C, p7 for C–C). With four tools × two formats × two bond types, one correct sign out of roughly a dozen opportunities is close to what chance would give, and the paper does not raise this.
  9. **Zenodo deposit not held.** doi.org/10.5281/zenodo.18664202 (p14) holds all 14,000 models; per-model coordinates, PC2 distributions and any re-analysis are outside the corpus.
  10. **Tags wanted but not available in the v3 vocabulary — none invented.** (a) A tag for *representation / input-format invariance* or *encoding-sensitivity* — this paper's entire subject has no tag; nothing in the Method, Protocol or Metric groups expresses "the same molecule described two ways". (b) A tag for *protonation / charge state handling*. (c) A tag for *ligand-geometry / bond-length quality*, which is what Figs 1–2 and Table 1 measure and which is orthogonal to pose accuracy. (d) A Protocol tag for **templates off but MSA on** — `no-template-no-msa` is wrong (full MSAs are used) and `templates-on` is wrong (AF3 templates are explicitly stripped), so no protocol tag was applied. (e) A System tag for a *bacterial periplasmic sensor / Cache domain*: `periplasmic-binding` was considered for BarA but a Cache sensor domain is not a periplasmic binding protein of the PBP fold, so `general-protein` was used instead; `kinase` was deliberately **not** applied because SCHEMA.md scopes it to protein kinases and only BarA's ligand-binding sensor domain (residues 31–178), not its kinase domain, is modelled.
  11. **Ambiguity in the v3 schema encountered during this extraction.** (i) `states_generated` and `state_metric` are written for protein conformational states and have no clean value for a paper whose object is ligand pose; both were answered honestly with an explicit NOT-APPLICABLE preface rather than forced. (ii) The PLOT `series:` slot has no defined value when point colour is a redundant re-encoding of the facet row — `series: none (1; redundant with facet)` was used in Figs 2B, 3C and 4C, but the grammar does not sanction it. (iii) The panel-splitting rule ("split when mark or measure differs") gives no guidance for a grid whose facet is a *product* of two variables; `facet: tool (4) × condition (4)` was written by analogy with the RENDER worked example. (iv) The schema has no row type for a **table**, yet Table 1 (p6) carries the paper's densest quantitative content; it was given a MATRIX row in section F and flagged as a table, which may not be the intended handling.
