## C. Conformational core

| Field | Value |
|---|---|
| `states_generated` | `ensemble + single-state`. Ensemble by construction — 500 models per protein per condition from 100 seeds (p9). But the ensembles collapse: per condition the output is usually one state at or near unanimity (Fig 1, p3: AF3 w/ ligand gives 500/500 for Myosin II, 499/500 ALDBP, 497/500 PDK; AF3 w/o ligand gives 500/500 for BLG, Myosin II, TEM, Hsp90; AmpC is 500/500 closed in both arms). The authors state the collapse themselves: "Here, the distributions are sharpened somewhat by AF3 relative to what is observed in the PDB" (p2). |
| `structural_priors_used` | Extensive, and legitimately so for a benchmark: (1) the test set is CryptoSite (14 of 15) plus K-Ras from Fesik and co-workers — "All proteins in the test set (see Table 1) originate from the CryptoSite database, except for K-Ras" (p7); the post-cutoff set is CryptoBench (p8). (2) Both open and closed reference PDB IDs are taken from those curated apo–holo pairs and are listed per protein (Tables 1 and 3, pp2, 8). (3) The "moving segment" — the residues on which every RMSD and every state call is computed — is inherited from CryptoSite for those proteins and hand-defined by the authors for the rest: "We defined it for other cases, as the protein segment (such as a loop, a side chain, or a helix) that is in a different conformation in the bound and unbound reference structures and would sterically clash with the reference ligand in the unbound state but not in the bound state" (p8). (4) The ligand supplied to AF3 is the cognate cryptic-site ligand read off the holo structure, by PDB chemical-component ID and SMILES (Tables 1 and 3; "the SMILES corresponding to the ligand listed for each case in Table 1 and 3 was used unless otherwise stated", p9). (5) Systems were chosen so that both states are deposited. None of this is a pipeline defect; it is what makes the comparison possible. |
| `oracle_leakage` | Enumerated by route. **Route 1 — structures as input or template: NONE FOUND.** "No structural templates were used" (p9); AF3 input is sequence + ligand SMILES only (protocol described pp8–9). **Route 2 — state annotations from a curated database driving templates or alignments: NONE FOUND for the pipeline.** CryptoSite/CryptoBench annotations (open/closed reference, moving segment) drive *evaluation*, not templates or MSAs; MSAs are plain MMseqs2 and are identical across conditions (pp8–9, and "the choice of ligand has no effect on the MSA", p5). **Route 3 — cluster labels from known states: NONE FOUND**; no clustering is performed (Analysis of conformations, p9). **Route 4 — criteria tuned against known states: PRESENT, and explicit.** "In addition, for cases where the classification of the PDB structures did not result in open conformations dominant for bound and closed dominant for unbound as expected (K-Ras and Ricin), we added the criterion that any structure or model for which moving segment residues would clash with the reference ligand (in the aligned reference structure) would be classified as closed" (p10). The same move is reported mid-Results for Hsp90/GluR2: "When clashing with the reference ligand was added as a criterion for being closed (likely needed since the moving segment is in a helix, see Supplementary Fig. 5), the PDB distributions for bound and unbound were open and closed as anticipated" (p3). This is a state-classification rule selected because the default rule did not return the expected answer, and it is applied to the AF3 models as well as the PDB structures ("any structure or model", p10). **Route 5 — success defined post hoc by RMSD to a structure they held: PRESENT by design.** State is called by RMSD of the moving segment to the held open and closed reference structures with a cutoff derived from those same references (p9); pose success is "whether the ligand pose RMSD was ≤2 Å from the X-ray position" (Fig 1 caption, p3). **Route 6 — best/worst labels assigned against a held reference: PARTIAL.** Ranking of models is by AF3's own pLDDT, not by the reference ("The top-ranked AF3 model by overall pLDDT", Fig 5 caption, p7), but "correct pose" / "incorrect pose" labels within the ensemble are assigned against the X-ray position (p3), and the three clash-analysis systems are selected post hoc — Fig 4C is "shown only for cases where clashes were detected" (p6). **Route 7 — design-level oracle: PRESENT, and this is the paper's main exposure.** The expected answer is declared before the result is read: the cognate holo ligand is supplied, the expected state per arm is stated in advance ("It is typical for most cryptic sites to be formed in the open conformation. In our dataset, for 15 of the 16 proteins, the bound reference structure is in the open conformation, and the unbound reference structure is in the closed conformation", p2), and the training-set membership of the answer is acknowledged: "This result is expected given that AF3 structures with ligands bound in the cryptic pocket exist and were in the AF3 training set" (p5). Table 1 footnote: "All proteins listed here were in the AF3 training set" (p2). Design-level, weaker than pipeline leakage — but combined with Route 4 it means the classification rule and the expected result were fixed jointly. |
| `prospective` | **no** for the 16-protein main set — every reference structure and every ligand identity was in hand, the state cutoff is derived from those references, and the classification criterion was amended for K-Ras, Ricin, Hsp90 and GluR2 after the first classification disagreed with expectation (pp3, 10). **partial** for the 8-case post-cutoff set (Table 3, p8): the target structures postdate the AF3 training cutoff so the model could not have memorised them, but the evaluation is still retrospective — reference states, moving segments and cognate ligands all come from the deposited holo structures. |
| `state_metric` | `binary predicate + RMSD-to-reference` (dual). **Operational definition, verbatim (p9):** "To classify each structure as open, closed, or 'other', we first computed the RMSD between the open and closed reference structures and used half of this value as the cutoff. Structures with an RMSD to the open reference below this threshold were assigned to the open state, while those within the threshold of the closed reference were assigned to the closed state. Structures that did not meet either condition were classified as 'other' state." Details: RMSD is computed on the moving segment only, with the moving segment excluded from the superposition; Cα-only for loop/helix moving segments, all-heavy-atom for single-side-chain moving segments (p9). **Threshold justification: NOT REPORTED** — "half of this value" is stated but never justified, and the cutoff is therefore a different absolute distance for every protein. **Additional, post-hoc criterion** (see `oracle_leakage` route 4): a clash of moving-segment residues with the aligned reference ligand forces the "closed" call, applied to K-Ras, Ricin (p10) and Hsp90/GluR2 (p3) because the default rule did not give the expected answer. Clash definition is operational: "classified as clashing if their interatomic distance to the original atom was less than 0.63 of the sum of their van der Waals radii" (p8) — **the 0.63 factor is not justified**. **PDB bound/unbound assignment** is a separate predicate (p8): bound if reference-ligand geometric centre is within 5.0 Å of the test-structure ligand centre, or if any reference-ligand atom is within 2.0 Å of any test-ligand atom; where the cryptic site is adjacent to the active site, bound additionally requires the ligand to clash with the unbound-structure moving segment. **Pose correctness** is a third predicate: ligand pose RMSD ≤2 Å to the X-ray position, with ≤2.5 Å also tabulated (Fig 1 caption p3; Table 2 p5) — **neither threshold is justified in the paper**. |
| `metric_saturation` | **Yes, numerically, in both directions.** Table 2 (p5): % of poses ≤2 Å ceilings at 100 for Myosin II, GluR2 and Hsp90 and sits at 99.8/99.4 for Ricin, ALDBP, BACE, PDK; the ≤2.5 Å column is at 99.8–100 for nine of sixteen proteins. It floors at exactly 0 for AR and AmpC in both columns. Conformational-state counts saturate too: multiple AF3 arms are 500/500 in one state (Fig 1, p3; e.g. AmpC 500/500 closed with and without ligand, Myosin II 500/500 open with ligand). PDB reference counts are the opposite problem — AR bound n = 7 and RNase A bound n = 7 (Fig 1, p3) — so "distribution agreement" is being judged against a handful of structures for some proteins. Axis-scale problems are recorded in the figure table's `hides`, not here. |
| `directional_control` | **Yes — the handle is the ligand, and it is the paper's whole subject.** Presence/absence of the cognate cryptic-site ligand switches the predicted state (p6, Conclusion). The *identity* of the ligand is a second, finer handle: GluR2 with ATPO gives predominantly open, GluR2 with glutamate gives correctly closed; TEM with one Xe gives closed, TEM with three Xe places all three overlapping in the closed cryptic pocket (p5). No seed, subsample-depth, template or partner handle is used. Mechanism offered (p5): "different ligand inputs alter the initial conditions and constraints of the denoising process, leading to distinct denoising trajectories even for the same protein sequence." |
| `anti_memorization_design` | **Yes, n = 8.** Cutoff defined as the AF3 training cutoff, 30 September 2021 (p8; note Table 3's column header reads "September 31 2021"). Construction: "The CryptoBench dataset, which is comprised of curated apo-holo structure pairs involving cryptic pocket formation, was first filtered to remove structures released prior to the AF3 training cutoff date (September 30 2021). Next, any remaining proteins with ≥90% sequence identity to proteins released to the PDB prior to this cutoff that had a ligand-bound or displayed an open state at the cryptic site location were removed. Four of the remaining proteins were not analyzed because they were similar to BACE in that the cryptic pocket presents as a shallow surface that closes to form a pocket only upon ligand binding" (p8). Of the 8, "Six of these had no structures of the protein released prior to the AF3 training date and two had only one closed structure in the PDB and none with the cryptic pocket formed" (p6). |
| `anti_memorization_control` | **RUN and analysed, but UNPOWERED (n = 8 < 10).** It is a full arm, not a set that merely exists: its own Results section, its own figure (Fig 6, p9), its own table (Table 3, p8), and the same with-ligand / without-ligand protocol. Result: "For five of the eight cases not in the AF3 training set (FTHFS, DHFR, DDL, UGT, and 12-Lox), AF3 with the ligand is able to correctly predict the open pocket. Thus, the majority of the time AF3 can successfully predict the cryptic site even though a structure with the cryptic pocket open was not in its training set" (p6). Two (pepA, DhbA) fall in Group 1c, one (ARHGEF2) is Group 4 — AF3 "misfolds the C-terminus where the cryptic pocket forms" (p6). Caveat the authors do not flag: all five successes are Group 1b, i.e. AF3 predicts the open pocket **with and without** the ligand (p6), so on this held-out set the ligand is not doing the discriminating work; the apo arm gives the same answer. |
| `controls_run` | See table below. |
| `confidence_as_discriminator` | **Yes for ligand pose, no for conformational state, and partially validated — with the validation showing where it fails.** Ligand pLDDT is regressed against pose RMSD: "ligand pLDDT scores over the AF3 structural models in the ensemble correlate somewhat with the ligand pose RMSD (with R² = 0.35)" (p7; Fig 4B legend on p6 labels the fit R² = 0.36). They validate it against physical plausibility and it breaks: "Three systems—MAPK, PDK, and Hsp90—illustrate that high ligand pLDDT does not universally guarantee physical plausibility… Hsp90 represents a more severe failure mode, in which the majority of models (~80%) exhibit steric clashes despite uniformly high ligand pLDDT scores" (p7); "ligand pLDDT for all Hsp90 models is very high (>95) despite most poses having a steric clash" (p5); and false negatives: "RNase A and TEM illustrate false-negative cases in which correct ligand poses are predicted with relatively low ligand pLDDT scores" (p7). Their own verdict: "ligand pLDDT can serve as a useful first-pass filter for prioritizing AF3 predictions. However, this relationship is not absolute" (p7). pLDDT is *not* used to call open vs closed — that is done by RMSD only. Overall pLDDT is used to pick the "top-ranked model" shown in renders (p2, p7). |

### `controls_run`

| control | what it rules out | page |
|---|---|---|
| **Apo arm — AF3 run on the same sequence and the same MSA with no ligand, 500 models, for all 24 proteins** | Rules out the possibility that the open/holo conformation is what AF3 returns unconditionally from sequence alone. It is the arm that makes the ligand effect attributable to the ligand. Result: "when AF3 predicts the same protein structures without a ligand, the closed conformation generally dominates" (p6). | p6, p9 |
| **Holo arm — AF3 co-folded with the cognate cryptic-site ligand (SMILES from Tables 1/3), 500 models** | The positive arm. Establishes that supplying the ligand shifts the ensemble to the pocket-open state in the majority of cases (13/16). | p2, p9 |
| **PDB reference distribution (bound and unbound sets assembled at ≥90% sequence identity) as the comparator for both arms** | Rules out scoring AF3 against a single crystal structure; makes "does the prediction track the deposited composition" a measurable question rather than an anecdote. Also the arm that exposes the mechanism: the 4 detrimental-memorization cases are those where PDB composition beats the ligand. | pp2, 8 |
| **Wrong/decoy ligand — GluR2 run with glutamate instead of the reference ligand ATPO** | Rules out "any ligand opens the pocket". Glutamate binds the same site with the pocket closed and AF3 correctly returns closed: "Glutamate is not large enough, given its position in the center of the cryptic pocket, to require the pocket to be open in order to bind" (p5). Ligand *identity*, not mere ligand presence, sets the state. | p5, p6 |
| **Ligand-stoichiometry decoy — TEM run with one Xe, then with three Xe** | Rules out AF3 having a physical occupancy constraint. With one Xe it predicts closed but places Xe in the wrong pocket; with three Xe it "places all 3 Xe as overlapping in the cryptic pocket with the protein in the closed conformation" — physically impossible. | p5, p7 |
| **Two-ligand competition — AR run with cryptic-site ligand RB1 and active-site ligand DHT simultaneously** | Rules out the RB1 misplacement being caused by the active site being empty. DHT is always placed correctly, RB1 still is not; in the top-ranked model and ~half the ensemble RB1 goes to a third, off-target surface pocket. | p5, Fig 5 p7 |
| **Input-order permutation — the AR RB1+DHT run repeated with the two ligands supplied in reverse order** | Rules out an input-ordering artefact. "the results were essentially the same (Supplementary Fig. 9a)". | p5 |
| **Ligand-size controls — AR run with EDO (4 heavy atoms) + DHT, and 2MI (10 heavy atoms) + DHT** | Rules out relative ligand size as the explanation for RB1 going to the active site. Neither smaller ligand was ever placed in the cryptic pocket. | p5 |
| **Post-training-cutoff test set, 8 proteins, both arms (Table 3, Fig 6)** | Rules out (partially) that the whole ligand effect is retrieval of a memorised holo structure. 5/8 correct open pocket with ligand. Underpowered at n = 8, and all 5 successes are Group 1b, i.e. open with *and* without ligand. | pp6, 8, 9 |
| **Seed-convergence / bootstrap control — models incrementally subsampled from the 100-seed pool, 100 bootstrap resamples per subsample size** | Rules out the reported population fractions being an artefact of finite seed sampling. "ensemble-level distributions converge rapidly with increasing numbers of seeds, with minimal changes observed beyond approximately 80 seeds" (p5). | pp5, 10 |
| **Steric-clash audit of "correct" poses (MAPK, PDK, Hsp90)** | Rules out pose RMSD ≤2 Å being sufficient evidence of a physically usable model — ~80% of Hsp90's correct-RMSD poses clash with the protein at high ligand pLDDT. | p5, Fig 4C p6 |
| **Comparison against the authors' own AF2 study on the identical 16-protein test set (ref 22)** | Isolates the contribution of ligand conditioning as opposed to the backbone: detrimental memorization drops from 8/16 (50%) with AF2 to 4/16 (25%) with AF3. Not a re-run arm — the AF2 numbers are quoted from the prior publication. | p4 |

## D. Claims

| Field | Value |
|---|---|
| `central_conclusion` | Supplying AF3 with the cognate cryptic-site ligand shifts the predicted ensemble onto the pocket-open (holo-competent) conformation in most cases, while the same sequence and MSA run without a ligand gives predominantly the pocket-closed conformation — so the ligand, not the MSA, selects the state. But the ligand does not always win: in 4 of 16 pre-cutoff proteins AF3 returns the closed conformation even with the ligand, and the authors attribute this to the closed state being far more numerous in the PDB. Ligand identity matters as much as ligand presence, ligand poses are frequently correct but sometimes sterically impossible at high confidence, and AF3 cannot resolve two simultaneously occupied sites. |
| `necessity_claims` | **All verbatim.** (1) p1, Abstract: "Variability in ligand position, however, suggests that generating ensembles of co-folded predictions is critical to enhancing the likelihood of obtaining a correct binding mode." (2) p1, Abstract: "AF3 is generally able to reproduce the scale of conformational change required for cryptic site formation." (3) p7: "In particular, RNase A and TEM illustrate false-negative cases in which correct ligand poses are predicted with relatively low ligand pLDDT scores. In these systems, ligand pLDDT values are broadly distributed across the ensemble, suggesting that reliance on a single top-ranked model may be insufficient and that broader ensemble inspection is required." (4) p7: "In practice, this indicates that ligand pLDDT should be complemented with independent plausibility checks, such as steric clash detection or light side-chain minimization, before downstream use in drug discovery." (5) p7: "This mismatch between apparent confidence and physical plausibility mirrors recent findings that co-folding models can produce high-confidence predictions that violate basic physical expectations, highlighting the need for independent plausibility checks (such as clash/strain filters or physics-based refinement) when interpreting ligand poses". (6) p7 — an impossibility claim about the model: "We have also seen that AF3 has no ability to discriminate when two ligands are directly overlapping (as in the case of TEM with multiple Xe ions predicted to bind in essentially the exact same site); AF3 is unaware that that is physically impossible." (7) p4 — impossibility for the predecessor: "The enhanced performance of AF3 may be due to the presence or absence of the ligand, which is obviously not possible with AF2." (8) p2 — a possibility claim, load-bearing in the other direction: "It is clear that the same MSA is capable of predicting a range of conformations at the scale (side chain movements, loop movements, and helical shifts) necessary for cryptic site formation." (9) p5: "This sensitivity to denoising trajectories further motivates the use of extensive ensemble sampling with multiple random seeds to explore a broader range of conformations." |
| `novelty_claims` | **NOT REPORTED.** No claim to be first, novel or unprecedented appears anywhere in the paper. The closest statements are framing and surprise rather than priority, and are quoted here so the absence is checkable: p2, "In this study, we examine the ability of AF3 to predict the ligand-bound conformation of cryptic sites both with and without the ligand present. This work builds on our previous study looking at the ability of AF2 to predict cryptic pockets" (p2); and p6, "Somewhat surprisingly, the choice of the ligand given to AF3 can also significantly impact the predictions." The Conclusion (pp6–7) makes no priority claim. |
| `stated_limits` | (1) Memorization is the standing alternative explanation for their own positive result: "while our results overall may reflect a bias toward memorized structural priors rather than flexible sampling of alternative conformations, the level of detrimental memorization appears to be reduced relative to what has previously been reported for AF2" (p6); and "This result is expected given that AF3 structures with ligands bound in the cryptic pocket exist and were in the AF3 training set" (p5). (2) Four named detrimental-memorization failures — RNase A, AmpC, AR, BACE (p3), "Over this test, we describe four cases of detrimental memorization (25%), all involving instances where AF3 with the ligand predicts the closed conformation instead of the correct open conformation" (p4). (3) Ligand misplacement into the orthosteric site for AR and AmpC (pp4, 7). (4) High-confidence physically impossible poses, up to ~80% of the Hsp90 ensemble (pp5, 7). (5) pLDDT is only a heuristic filter (p7). (6) AF3 cannot handle two overlapping/simultaneous ligands (p7). (7) Very small PDB reference sets for some proteins — "there are very few structures" (AR, p4), "there are very few bound structures" (RNase A, p3). (8) A portion of the "other" state may be noise: "a portion of these 'other' conformations could arise from stochastic diffusion noise" (p10). (9) No inferential statistics: "No inferential statistical tests were performed in this study. All analyses are descriptive" (p10). (10) AF3 outputs "are not biological or experimental replicates" (p10). (11) The overall honest close: "The challenge will be in identifying those conformations with actionable cryptic pockets that are revealed among the many conformations generated" (p7). |
| `stance` | **`precedent` + `contrast`** (provisional — the user's call). *Precedent on findings*: it is a direct, published, peer-reviewed demonstration that the ligand is a working directional handle on AF3's conformational output at the pocket-geometry level, with an explicit apo control arm and a decoy-ligand arm — the same experiment as ours, transposed from global conformational state to local pocket geometry. *Contrast on rigour*: the state-classification criterion was amended for four proteins because the first classification did not give the expected result (pp3, 10); no threshold in the paper is justified; the post-cutoff control is n = 8 and its five successes are all cases where the apo arm already gives the open pocket, so the held-out data does not actually test the ligand effect; and no inferential statistics are run. |
