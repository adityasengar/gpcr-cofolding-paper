# W-9 — Phase 4h permutation-null p-values as the load-bearing null

## Claim as previously stated

Phase 4h reported permutation-null 95% bands for the eight backbone × axis
combinations of the tilt and delta_to_active shifts, with all eight observed
deltas exceeding the null band at p < 0.001. The dossier presented these as
the strongest available evidence for the arm-shift effect.

## Retraction

**Withdrawn as the load-bearing null.** Shuffling arm labels within a
receptor tests whether adding a Gα partner changes the receptor's structure.
It does — trivially — because there is now a large helical bundle docked at
the cytoplasmic face. The permutation null does not test what the paper
actually claims. Any p < 0.001 quoted from Phase 4h is measuring the wrong
thing at the wrong grain.

## The correct null lives in Block B

The load-bearing null is a **wrong partner**: given a shuffled or decoy Gα,
does the receptor still reach an active-state geometry? Block B answered
this — shuffled arms reach substantial active rates, substantially deflating
the specificity claim that Block A's headline appears to underwrite.

## What the manuscript should say

The Block A permutation-null p-values should be:

- Reported (they are trivially significant, and reviewers will look) BUT
- Framed as "significant against a within-receptor permutation" with an
  immediate pointer to Block B's wrong-partner analysis as the load-bearing
  specificity test.

Alternatively — and this is stronger — drop Phase 4h's p-values from the
headline framing and cite Block B's null directly. That's a paper-level
decision.
