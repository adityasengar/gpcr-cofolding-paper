# C-2 — Class B cognate tilt is 100% ceiling-saturated

## Caveat

The Class B two-instrument predicate uses (kink AND tilt). On Block A,
cognate-arm TM6 tilt is 100% above the threshold (IQR [22.24, 22.72] Å,
threshold 14.932 Å). The tilt axis cannot discriminate apo from cognate
in Class B; only the kink axis does. Additionally, at row grain,
tilt-active ⊂ kink-active on every Class B cognate row — the two axes
are non-independent.

## Affects

- Any Class B active-call rate on the tilt axis alone (uninformative).
- Any cross-class comparison of active-call rate that treats Class A and
  Class B tilt symmetrically.
- Class B agreement rate at 81.64% (κ=0.31 fair) is a within-Class-B
  measurement; the low κ reflects the tilt-active ⊂ kink-active dependence.
