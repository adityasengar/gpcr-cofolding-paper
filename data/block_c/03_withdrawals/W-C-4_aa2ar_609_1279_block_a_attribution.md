# W-C-4 — AA2AR "609 active-like / 1,279 inactive-like at 1,888 rows" attribution to Block A

**Retracted**: v1 attribution of AA2AR bimodality numbers to Block A.

**Reason**: the figure "609 / 1,279 at 1,888 rows" is from the **v3.6b
campaign** (17,568 rows per receptor, `PIPELINE_INTERPRETATION.md`), NOT
from Block A (which used n = 100 rows per receptor via the (5, 5) grid
pinned in PREREG §9). At Block A row counts, AA2AR is unimodal.

**Correction**: `experiments/018_block_a_switch_test/analysis/verification/aa2ar_unimodal_block_a_counter.json`
reports the Block A-scale AA2AR distribution. Manuscript should cite the
Block A number for Block A claims and the v3.6b number (with campaign
attribution) if the bimodality is invoked separately.

**Cite** in Discussion §AA2AR standing anomaly footnote.
